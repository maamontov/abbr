# Аббревиатуры

Карточная PWA для российской аудитории, в первую очередь для iPhone. 250 сокращений, 50 карточек, четыре режима, 1–8 игроков на одном устройстве. Интерфейс, карточки, кубик, таймер, звуки и справочник работают без сети после первой загрузки. Ответы произносят вслух и проверяют в приложении; правильность отмечают сами игроки.

Статический HTML/CSS/JavaScript без серверной части, внешних шрифтов, CDN, аналитики и зависимостей приложения. Для разработки достаточно Node.js 20+; `npm install` не нужен.

## Запуск на Linux или macOS

```sh
npm run dev
```

Откройте **http://localhost:5173**. Другой порт: `PORT=8080 npm run dev`.

Для проверки готового пакета:

```sh
npm run build
SERVE_DIST=1 npm run dev
```

Сборка складывает приложение в `dist/` и меняет версию офлайн-кеша по содержимому файлов. Node нужен только для разработки и сборки; на хостинге исполняется обычная статика.

## GitHub Pages

1. Загрузите проект в свой GitHub-репозиторий с основной веткой `main`.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` выполнит проверки, соберёт `dist/` и опубликует игру при push в `main`. Его также можно запустить вручную в Actions.
4. Откройте адрес, показанный в задании `deploy`, например `https://имя.github.io/abbr/`.

Все URL относительные: приложение работает в корне домена и в подпапке репозитория. Для другого статического хостинга достаточно разместить содержимое `dist/` по HTTPS. Настройка соответствует [официальному workflow GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Установка на iPhone и офлайн

1. Откройте HTTPS-адрес игры в Safari.
2. Нажмите **Поделиться → На экран Домой → Добавить**.
3. Запустите приложение с новой иконки и дождитесь отметки **«Можно офлайн»**.
4. Включите авиарежим, закройте приложение и откройте снова. Игра, справочник и сохранённая партия доступны без интернета.

Первая загрузка требует сети. `localhost` разрешает service worker при разработке; обычный HTTP по IP-адресу в локальной сети для офлайна не подходит. Для проверки на iPhone используйте HTTPS, например GitHub Pages. Установка и автономное открытие основаны на [поддержке домашних веб-приложений в WebKit](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/).

Service worker атомарно сохраняет весь пакет. Обновление не меняет файлы посреди партии: новая версия активируется, когда закрыты все окна предыдущей. Кеш и сохранения разделены по пути приложения, чтобы несколько проектов на одном GitHub Pages домене не мешали друг другу. Браузер может удалить данные сайта при очистке или нехватке места; приложение запрашивает постоянное хранилище, когда API доступно. [Политика хранения WebKit](https://webkit.org/blog/14403/updates-to-storage-policy/).

## Правила в приложении

- **По очереди:** любая колода от 10 до 50 карточек, выбранный номер 1–5, ходы по кругу. Верно — карточка и очко игроку; ошибка — карточка вниз колоды. Конец, когда вся колода разобрана.
- **На время:** по одной минуте на ход, общая колода. Верный ответ забирает карточку, ошибку или пропуск возвращаем вниз. После минуты телефон переходит следующему. Минутные ходы идут по кругу до конца колоды, как предусмотрено общим правилом игры.
- **Кто первый:** ведущий читает сокращение вслух, после открытия ответа отмечает первого верно ответившего. Если никто не угадал, карточка идёт вниз. Ведущий может быть одним из игроков, отдельное устройство не требуется.
- **Рандом:** встроенный кубик выбирает номер 1–5; шестёрка передаёт ход, оставляя карточку на месте. Верный ответ приносит карточку, ошибка возвращает её вниз.

Встроенный справочник доступен как подсказка. Его открытие в режиме на время ставит таймер на паузу; это явно указано в правилах, чтобы компания могла договориться заранее. Пауза также включается при сворачивании приложения. Счёт сохраняется после каждого действия; повторное открытие партии требует подтвердить готовность.

Ничья сохраняет всех победителей. Можно завершить партию досрочно и сравнить текущий счёт.

## Контент и дизайн

Собственный набор: пять тем по 50 сокращений, по одной теме на каждом из пяти мест карточки. Номера распределяют темы по колоде. Используются распространённые российские значения; у отдельных сокращений бывают и другие расшифровки. Историческое значение ТАСС помечено отдельно. Данные редактируются в `public/data/abbreviations.json`; загрузчик проверяет количество, уникальность и темы. Это авторский цифровой набор, не скан и не копия карточек печатной игры.

Основные справочные источники для названий: [ФНС](https://www.nalog.gov.ru/rn99/), [Социальный фонд России](https://school.sfr.gov.ru/o-soc-fonde.html), [МЧС](https://mchs.gov.ru/ministerstvo/o-ministerstve/obyazannosti-ministerstva/polnomochiya-mchs-rossii), [классификаторы Росстата](https://www.rosstat.gov.ru/classification).

Дизайн: объёмная колода, переворот карточки, пружинящие нажатия, бросок кубика, анимация победы; движения используют transform и opacity. Системные шрифты, области нажатия от 44 px, safe areas iPhone, клавиатурная навигация, подписи элементов и скрытие ответа от скринридера до проверки. Системный `prefers-reduced-motion` и внутренняя настройка отключают 3D и декоративное движение. Звук синтезируется локально после взаимодействия и отключается в настройках.

Ориентиры: [Apple: дизайн игр](https://developer.apple.com/design/human-interface-guidelines/designing-for-games), [движение](https://developer.apple.com/design/human-interface-guidelines/motion), [размеры элементов и читаемость](https://developer.apple.com/design/tips/).

## Проверки

```sh
npm run check
npm test
npm run build
```

`tests/game.test.mjs` проверяет игровой движок: состав колоды, все режимы, очередность, ничью, возврат карточек, кубик, таймер на границе минуты, паузу, сохранение и повреждённые данные.

Браузерные проверки требуют Playwright, который не включён в приложение:

```sh
npm install --no-save playwright
npx playwright install chromium
# В другом терминале запустите npm run dev
npm run test:browser
```

Если Playwright установлен глобально, сценарий найдёт его автоматически. Скриншоты сохраняются в `test-results/`. Проверяется полная партия, четыре режима, отсутствие переполнения при ширине 320–1365 px, поиск, пауза, восстановление и холодная перезагрузка с отключённой сетью. Эмуляция размера iPhone в Chromium не заменяет итоговую проверку Safari и установки с реального iPhone.

Проверка подпапки Pages:

```sh
PORT=5174 BASE_PATH=/abbr/ SERVE_DIST=1 npm run dev
# В другом терминале, когда основной dev-сервер тоже запущен:
SUBPATH_URL=http://localhost:5174/abbr/ npm run test:browser
```
